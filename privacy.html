Privacy Policy

Last updated: 2026-04-09

AI Memo Wrap is a browser extension for capturing selected text from webpages and organizing it into memos. This page also includes Chrome Web Store data disclosure details.

What Data We Process

1) Local memo data (default mode)

  • Selected text content captured by user action
  • Memo metadata (title, tags, category, timestamp, URL/source)
  • Local settings (language, UI preferences, feature toggles)

Stored locally in browser via chrome.storage.local.

2) Optional cloud account data (only when Cloud Sync is enabled)

  • Email address used for Supabase authentication
  • Cloud user identifier and session tokens
  • Memo records user chooses to sync

3) Optional Notion sync data (only when Notion is connected)

  • OAuth authorization result for user’s own Notion workspace/account
  • Memo content and metadata explicitly synced by user

Chrome Web Store Data Disclosure

Do you sell personal data?

No.

Is data collection optional?

Yes for cloud sync and Notion sync. Local capture works without account login.

Encrypted in transit?

Yes, network communication uses HTTPS (Supabase and Notion API/edge functions).

Deletion controls

Users can delete local memos in extension UI; cloud and Notion data can be removed from user-owned services.

How We Use Data

  • Provide capture, memo management, filtering, and export functionality.
  • Sync memos across devices only when user enables Cloud Sync.
  • Send memos to user’s own Notion workspace only on user-triggered sync.

Third-Party Services

  • Supabase (optional authentication and cloud storage)
  • Notion API (optional user-authorized sync)
