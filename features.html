Product capabilities

Features for web research, notes, and knowledge workflows

Capture highlights from any webpage, organize them with tags and categories, then copy, export, or sync them when you are ready.

1) One-Click Highlight Capture

Select text on any webpage and save with source URL, title, and timestamp.

2) Searchable Memo Library

Turn saved highlights into a lightweight library with titles, source links, and full-text search.

3) Tags, Categories & Sessions

Use #tag filters, custom categories, and research sessions to group related notes.

4) Rich Copy & Share Digest

Copy single notes, rich digests, subject lines, previews, body copy, and CTA snippets.

5) Batch Export + Optional Notion Sync

Select multiple memos, export CSV, copy to clipboard, or sync to your Notion workspace.

6) Local-first + Optional Cloud

Use local storage by default and enable account-based cloud sync only when needed.

7) Privacy Mode

Redact source URL and page title for sensitive browsing sessions while still saving the note.
